The goal of this project is to create a web application that allows users to catalog of my electronic components, arduino boards, sensors, etc.

This is the previous version description of  https://alvarosaburido.dev/portfolio/smidae, however we shouldn't use the same tech stack at all just the idea

Tech stack
- Nuxt 
- Nuxt UI components + tailwind, pink primary color #FF7C77
- Nuxt server
- sqlite3 database + drizzle ORM
- Each component should have a markdown file.

The application should allow users to:
- Add a new component to the catalog
- View the catalog
- Search the catalog
- Filter the catalog
- Sort the catalog
- Add a new component to the catalog
- View the catalog
- Search the catalog
- Filter the catalog
- Sort the catalog
- Upload images of the components
- Add a description of the component
- upload pdf with datasheets and schematics
- Able to add schematics
- Mobile should work similar to a mobile app.
-

Mantainability
- The database schema should be easy to migrate, seed. 
- Deployable on docker, cloudflare pages, etc.
